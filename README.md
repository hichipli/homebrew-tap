# hichipli/homebrew-tap

Homebrew casks for apps by [Hongming (Chip) Li](https://github.com/hichipli).

## CiteBar

[CiteBar](https://www.citebar.org/) keeps your Google Scholar citations in the Mac menu bar.

```bash
brew install --cask hichipli/tap/citebar
```

CiteBar updates itself, so there's no need to run `brew upgrade` for it. The cask follows each new release automatically.
